# Setup — Harsh GitHub Profile

This ZIP is ready for the special GitHub profile repository **Harsh-DevOps117/Harsh-DevOps117**.

1. Create that repository (public) if it does not already exist.
2. Place **README.md** at the repository root.
3. Place **assets/** next to README.md (do not flatten or rename it).
4. Commit and push. GitHub automatically shows the README on your profile.

```bash
# From the profile repository directory, after extracting the ZIP contents:
git add README.md assets/
git commit -m "Design custom SVG GitHub profile"
git push origin main
```

If your profile repository uses a different branch name, use that branch instead of `main`.

All SVGs are original, vector, and self-contained. No external image services are required.
The code repo links were checked on 28 Oct 2026. This package does not publish changes to your GitHub account.
